# 图谱事实回归评测

`scripts/evaluate_graph_facts.py` 读取当前图谱字段；评测标准与生产抽取完全分开。它用于冻结样本的回归检查，不把尚未标注的节点当作错误，也不输出全图精确率。

```powershell
python scripts/evaluate_graph_facts.py --graph path/to/graph.json --gold path/to/gold.json --output path/to/report.json
```

标准文件包含 `version`、`scope`、`review_status` 和 `facts`。每条事实的 `id` 唯一，按路线和标准化起止桩号寻找边坡，不依赖 AUTO 编号或节点 ID。

```json
{
  "version": "example-v1",
  "scope": "一个边坡的侧别及一个产状，不是完整图谱标注",
  "review_status": "synthetic example",
  "facts": [
    {
      "id": "side",
      "route": "G999",
      "station": "K1+000-K1+100",
      "node_type": "Slope",
      "expected": {"side": "右侧"}
    },
    {
      "id": "plane",
      "route": "G999",
      "station": "K1+000-K1+100",
      "node_type": "StructuralPlane",
      "relation": "DEVELOPS_STRUCTURAL_PLANE",
      "collection_member": true,
      "expected": {"dip_direction": 120, "dip_angle": 45}
    }
  ]
}
```

- 主节点评主节点；子节点必须通过指定方向和关系连到目标边坡。候选断言中出现相同数字不能替主节点得分。
- `where` 指定工况、危岩体、破坏模式等事实身份。`expected` 的所有字段必须在同一个节点上匹配。区间、倾向和倾角不可跨节点拼数。
- 数值严格按数值比较，默认绝对容差 `1e-6`；单位必须由字段名或 `where` 明确，不自动换算。只有显式写入 `aliases` 的同义项才被归一化。
- 同一标量事实存在正确值和其他值，标记 `conflict`，不算通过。正确重复表示计入 `duplicate_matches`。`collection_member: true` 用于集合中的一个事实，其他集合成员未标注，不据此判冲突。
- `expect_absent: true` 可定义禁止出现的表示；没有目标边坡时不能靠空图通过。`description_contains` 只能用于限定已核定的原文对象，不用于自动判断所有长句真假。
- 结果区分 `pass / wrong / missing / conflict / violation / missing_owner / ambiguous_owner`。缺少身份字段造成的未命中是缺失；不推测模型本来想表达什么。
- 实际标准应保留来源文件哈希、PDF物理页码、引文、审核者和审核状态。CLI记录图谱与标准文件哈希；源PDF和解析缓存的版本一致性须在生成/复测流程中验证，不能仅凭命令成功认定。

## 对象与来源范围

典型计算断面的尺寸保存在 `Slope.scoped_geometry`，包含断面编号、原句和来源页，不替代坡段一般高度和坡度。稳定性分析分别保留 `analysis_scope`、`body_id`、`failure_mode`、`section` 和 `condition`；不同危岩体或断面不能因为数值相同而合并。

一个编号章节同时包含多个坡段、计算表没有唯一坡段依据时，结果通过 `DOCUMENTS_STABILITY_ANALYSIS` 连到来源文档，保留 `candidate_stations` 和待核实标记，不自动挂到任一坡段的 `HAS_STABILITY_ANALYSIS`。危岩体、未知范围及存在质量问题的结果不进入整坡筛查。

跨栏表格在同页相邻的表头片段与数据片段列数一致、工况及系数能按表头完整解析、没有新章节或新表题隔断时拼接。另支持右栏底部到紧邻下一页左栏顶部的续表：额外要求表宽接近、每行都能完整解析、前表含有效计算结果。均保留两段来源，不能依靠数字相邻推测列含义。表格内部多余空列只在明确表头跨度内至多有一个非空值时归并；有歧义的跨度不猜列关系。

最大坡高不推造最小值，也不覆盖其他来源已明确的完整高度区间。`scoped_geometry`还保存`设计开挖`与`设计单级`及原句，避免每级高度成为整坡高度。仅在一般坡度缺失且该片段只有一个明确坡面方向对时补坡度；明确的坡度区间优先。土质滑体和下伏岩质滑床、岩质主体和表层覆盖物分别理解，不因同段含土岩词项就覆盖原文明示的主体分类。

复测应同时设置正例和禁止出现的反例，核验关联对象、工况、编号及证据。测试数据只存在预期数字、未覆盖额外输出时，不能把“通过率”称作全图精确率。开发时发现的新问题一旦用于修复，该样本就应转为开发回归集，另留未参与调参的检查样本。

限定范围的精确率/召回率评测应同时收集原文应有事实及该范围内全部输出，固定事实粒度、身份字段、去重规则和排除项。错误替代通常同时产生一个FP和一个FN。每轮保留原图、首次分数及评分口径；不能删除难题、放宽断面要求或改用“只匹配数字”来提高完整事实指标。发布前检查重点指标、既有正确事实、原回归集和全库受影响字段；未复核的新变化不得自动批准。没有完整全库标注时，不宣称总体精确率/召回率获得保证。

计算对象可来自同一坡段内、按阅读顺序位于表格之前的明确计算小节。跨页延续时保留小节标题及文本块证据；后续编号小节会结束上下文，表格行号和规范条款号不作为新小节。只有“单个危岩体计算”小节内唯一明确编号才能补块体身份，不能从整章碰巧出现的编号推定。上部土质、下部岩质等局部计算结果保留局部范围，不进入整坡筛查。

表格补充正文剖面或块体身份须满足同源、同页、同工况、同系数，已有身份不冲突，且本地只有一个对应表格结果。相同数字出现在多个计算对象时保留歧义。几何量同时识别数值与限定词：“最大高差”保留上界；山脊、山丘等周边地形高度单独保存。岩性和产状须由同句地层主语连接；“岩体”泛称只有在同坡段存在相同方向对的明确岩层观测时才去除重复，明确节理不因数值相同而删除。

这些规则的回归测试应更换数字、对象名、剖面和块体编号，并包含多对象同数值、邻坡、句界和章节切换反例。私有答案只用于评分，不参与生产抽取。离线展示不嵌入完整处理候选审计表；完整审计仍保留在机器可读图谱和独立审计文件中。
