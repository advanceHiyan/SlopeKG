# 旧文字 deep 已移除

2026-10-25，根据用户明确要求删除。

旧 deep 只对基础流程已发现的对象选取文字片段，不能独立解决漏对象、复杂图纸和表格错配。在参与过开发的历史200项对照中，basic为164正确、4误报、36漏报，历史deep候选重校验为165正确、9误报、35漏报。这是删除旧路线的项目内依据，不能作为全库效果或新版多模态效果。

当前支持两条路线：

- `legacy`：本地 basic，包括逐页解析、按需OCR、规则抽取和基础图谱。
- `multimodal`：按明确选择的PDF和模型配置进行原页视觉识别、独立复读、核验与查漏，候选独立保存，不自动写入图谱。

已删除旧文字 deep 的调用编排、提示词、片段取样、专用返回校验、独立文字抽取脚本、网页按钮、候选查询接口和导出选项。CLI不再接受`--deep`、`--mode deep`、`--llm-model`及`--no-llm`。HTTP拒绝旧deep模式及其文字模型参数，不会静默回退。缓存重建只重建basic，不读取旧文字候选。

原始资料、历史结果、审核记录和模型配置保留；DeepSeek仍可作为多模态模型使用，规范规则抽取自身的文字接口不属于这次删除的PDF deep路线。未重跑生产PDF或付费模型。已有本地服务需要重启才能加载变更；之后基础更新会生成当前basic结果。

旧文档中有关basic/deep并存的运行说明属于历史记录，以本说明和当前CLI为准。

验证：415项后端单元回归、19项相关浏览器回归通过。新增删除回归检查旧CLI/HTTP参数被拒绝、原成果不被错误调用覆盖，以及basic与本地缓存重建不读取旧文字候选或调用模型。这些检查验证删除与功能兼容，不衡量多模态识别准确率。
