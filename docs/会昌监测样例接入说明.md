# 会昌监测样例接入说明

首轮范围：会昌八份代表表，8类指标、40,620条原始记录。完整目录27表中的其他文件尚未纳入。输入固定在`data/202610/监测数据/会昌/`，不扫描其他工点。

## 使用

1. 在项目已有Python环境运行`python scripts/import_huichang_monitoring.py`。
2. 启动或重启本地服务，打开`/web/monitoring.html`，也可从“数据与接口”的会昌入口进入。
3. 默认日期为2026-05-25至09-01，100个日历日。更改日期后点击“读取日期范围”，拖动回放条设置截止日期；多分量曲线可单独选择分量。
4. 原始观测每页20条，保留源文件、工作表、行号及单元格。原表下载会重新检查SHA-256；文件变化时拒绝冒用旧导入版本。
5. 点击“导出当前日期报告”生成自包含HTML。离线报告保存曲线、来源、整批质量及每个日期最后一条代表记录，完整高频记录保存在本地数据层。

## 数据与解释

SQLite保存原始观测与拆分分量，目录记录输入哈希、导入版本、处理运行和来源关系。重新导入相同输入不增加重复观测；一次构建全部成功后才发布新目录。数据库查询为只读、分页和日期过滤。

曲线按原始记录日期取最后一条已记录观测，这属于展示汇总，不宣称是监测平台的官方日统计定义。中间无记录日保留空值，曲线断开；日期解析失败、数值解析失败和重复时间保留原记录及标记，不填成正常观测。日期过滤不表示数据在当天零点已经可用。

仅含水率表头已明确百分比；其他单位、分量名称、正负方向、基准和时区保持未知。地下水零值不能直接解释为无水或离线。最大相邻变化用于定位回查片段，不能自行作为工程危险判据。

独立监测来源图包含候选工点、来源设备、系列、源表、质量摘要和处理运行，共34节点、48关系；没有把未确认工点写成现有正式边坡或开放风险发布。后续需确认逐设备对应和字段后，再开展物理指标及未来观测预测基线。

## 接口

| 接口 | 用途 |
| --- | --- |
| GET `/api/monitoring/catalog` | 当前样例、字段与质量摘要 |
| GET `/api/monitoring/observations` | `series_id`、`start`、`end`、`limit`、`offset`分页原始观测；`include_invalid_time=true`可同时查看无法解析时间的记录 |
| GET `/api/monitoring/replay` | 日期范围内的逐日展示与源记录 |
| GET `/api/monitoring/graph` | 独立监测来源关系摘要 |
| GET `/api/monitoring/source?series_id=...` | 下载与当前导入哈希一致的原表 |
| POST `/api/export/monitoring` | 以`start`、`end`导出日期范围报告；已有同名报告不会被覆盖 |

监测观测接口在有数据时显示`implemented_pilot`和明确的会昌范围。环境、近期巡检等其他预留接口不因此变成已接入；现有风险就绪检查仍保留业务审核要求。

## 验证

本轮全量源表核对40,620条时间和值、8份源文件及下载哈希；检查100天默认回放、截止日期、多分量选择、独立来源图、在线导出与离线交互。测试包含空档、零值、重复时间、非有限/公式值、无效查询、重复导入、失败时保留上一导入、读取失败时清除旧画面，以及原表变化后的下载拒绝。

全量后端测试224项通过；18项网页测试通过，最终会昌功能另有真实浏览器核查。以上证明本轮功能与来源一致性，不属于专业风险预测效果评测。
