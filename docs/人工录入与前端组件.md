# 人工录入与前端组件

风险研判页在边坡详情右上角提供“人工录入”，展开后按工程与环境、近期观测与处置、稳定性与后果分组。空白项沿用自动提取值；已有人工值显示在输入框中，清空后保存可撤销该字段覆盖。保存后原地刷新统计和详情，保留搜索及当前选中边坡。

近期观测须填写日期。表单加载失败时提供重新读取，不用空记录代替未读到的已有记录。保存和撤销期间禁用重复操作，失败保留当前输入并显示原因；打开录入表单时暂停后台版本变化引起的整页刷新。撤销仍需确认，原PDF自动提取结果保留。

规则库的“新建规则”提供分组表单、条件增删、草稿/启用状态和收起操作。“已有值”条件无需比较值；最多10个条件。保存成功后更新候选列表与详情，新增表单复位收起。删除失败保留记录并允许重试。规则仍只影响P1—P4复核顺序，不产生正式风险等级。

## 职责划分

| 模块 | 职责 |
|---|---|
| `web/pages.css` | 共享按钮、图标尺寸、悬停/键盘焦点、危险操作、表单分组及手机布局 |
| `web/api.js` | 统一JSON请求及接口错误处理；原`getJson`兼容保留 |
| `web/manual-entry.js` | 人工补录和新建规则表单、读取重试、防重复提交、保存状态 |
| `web/portal.js`、`web/rules.js` | 页面数据展示、筛选及保存后的局部刷新 |
| `manual_contract.py` | 字段、分组、条件运算符及公开表单约定；返回副本防止调用方改变全局定义 |
| `manual_validation.py` | 不读写磁盘的值校验、日期检查、补录输入及规则结构化 |
| `manual.py` | 数据持久化、人工值覆盖、规则合并和审计记录；保留原公开导入入口 |

数据文件位置和人工规则执行条件保持兼容。数值字段拒绝布尔值，避免`true`被当作数字1；提供的日期必须是有效的`YYYY-MM-DD`。不支持自动执行的规则继续保存其限制说明，不会因前端整理被自动启用。

浏览器回归使用模拟接口，后端使用临时目录，不写入项目真实人工记录。只读截图通过临时本机服务查看真实字段，并拦截全部非GET请求；不启动PDF目录监听、OCR或模型。
