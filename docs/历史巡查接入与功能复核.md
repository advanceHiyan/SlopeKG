# 历史巡查接入与功能复核

本轮保留会昌监测原值回放，并新增历史巡查检索。数据用于查找历史病害、核对原表和检查监测变化，不自动产生新的风险结论。

## 使用

启动现有本地服务，从“数据与接口”进入“历史巡查检索”。可以按边坡/桥梁、日期、桩号、方向、桥名和问题原文检索，分页查看并下载核验后的原表。每条记录保留工作表、原行号和字段位置。长公式及其他原始字段收在“其他原始字段”中，展开可核对。

原文件为 `data/202610/其他/日常巡查记录.xlsx`，已接入88条记录：边坡72条、桥梁16条。已知日期为2022-01-04至2022-08-12，桥梁工作表第10、17行缺少日期，保持缺失。勾选“含日期缺失记录”时，缺日期记录可随其他条件一起检索；取消勾选后，日期筛选只返回日期已知的记录。

路线和具体边坡对应尚未提供。桩号范围保留原文，不拆成假定的单个边坡，不进入近期巡查接口或风险评价流程。原表中的Excel公式按原公式保存，不把缺少计算结果的公式猜成数值。

需要重新导入时，使用已有环境运行：

```powershell
python scripts/import_inspection_history.py
```

接口为 `/api/inspections/history`、`/api/inspections/history/catalog` 和 `/api/inspections/history/source`。数据快照及目录位于 `output/demo/inspection_history/`。原表下载校验文件内容是否与导入版本一致，避免提供已被替换的来源。

## 已修复的问题

- 监测曲线只有单日值或孤立点时，原SVG路径无法显示数据点。现在显示独立圆点，并保留缺测断档。
- 原值查询失败后重新成功时，旧错误提示和计数可能残留。现在在新查询开始时清理。
- 监测数据快照被损坏或删除时，接口目录可能仍显示已接入或报错中断。现在校验文件内容，显示数据不可用并保留其他接口信息。
- 多个请求同时导出相同名称的监测报告时，可能互相覆盖。现在先原子预留独立文件名，导出失败会清理预留文件；离线HTML整体替换写入，避免读取半成品。
- PDF内容变化但大小和修改时间相同时，旧目录可能仍标为有效。现在已有来源校验和的文件还会校验内容。
- 导入监测表时，哈希读取与Excel解析曾分两次读取文件。现在解析同一份已读取的字节，确保来源校验和对应实际解析内容。

## 验证与数据选择

237项后端测试、9项本地语料集成测试、20项浏览器测试通过。88条巡查逐项核对全部原始字段和来源行；实际页面、来源下载、桌面/窄屏以及在线/离线监测单点显示已验证。

会昌8表40620条监测原值可以继续用于历史回放、质量查看和来源追溯。监测单位、分量、累计基准和逐设备归属仍需核实，确认后再计算速率、降雨指标或预测基线。其他县监测存在目录归属、倾角重复版本等疑问；PNG缺少可靠空间/日期信息；旧报告没有确认的规则和评价标签。这些资料本轮保留为资料库，等对应功能需要且条件满足时再接入。
