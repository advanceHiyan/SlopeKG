**后续视觉试验有改善，但未修好生产主干。** 对同3PDF的17页作临时对照，AI助手逐页查看并核对633条输出记录：文字、文字加图像、仅图像分别发现7/7个选定区段，8项兼容事实召回为8/8、7/8、7/8。仍有错列、尺寸误读、范围未决和冲突漏报；不同组输出粒度不同，不能把记录正确比例当总体精确率，也不能把这些开发样本称为盲测。试验结果未写入生产图谱。

**发布状态须与代码分开看。** 10月15日独立修复后曾重建basic并验证版本一致；此后API适配器继续更新。本次读取状态：basic与当前实现不同，deep无版本记录，尚不能称全部成果已跟上最新代码。正式deep仍读取文字，模型支持图像不等于生产流程已经改成视觉抽取。

独立修复时330项后端/语料检查、36项浏览器检查通过，原正确项逐条保留；这不证明后续所有变更或全部内容质量已经验收。本次只精简文档并核对状态，未改代码、重跑识别或调用模型。

## 3. 剩下怎么处理

运行问题已解除；剩余重点是**对象发现、版面/表格读取、事实归属及查漏**相互影响的流程问题。当前仍有固定双栏/坐标假设，不能靠给每个文件加例外解决。

通用改造方向：模型直接看完整原页发现对象 → 表格保留表头、空单元格与坐标 → 每条事实绑定对象、范围、角色和工况 → 从原页另外查漏，疑点局部放大重读。保留已有来源、失败状态和冲突提示；不按桩号或答案写分支。正式集成前须检验原正确项保留，以及未见整文件上的精确率和召回率，当前不能声称达到人工水平。
