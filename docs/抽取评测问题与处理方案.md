# 抽取评测问题与处理方案

更新：2026-10-19。对照学弟10月13日的9份资料筛查及早期图谱评估，核对当前代码和实际测试。

**结论：没有全部解决。4项运行BUG已有修复验收；新多模态路线已接入命令行和网页，并针对语义、漏读和错配增加了机制，但尚未在当前版本逐项通过学弟原问题的内容验收。不能把“有新方法”当成“原问题全部消失”。**

## 2. 新方法现在实际做到哪一步

**已成为可运行功能。** 当前版本为visual-v11，命令行和网页可显式选择multimodal；默认basic/deep仍走legacy旧路线。新候选单独保存，不自动进入旧图谱或风险数据集。此前“仍只是临时旁路、没有网页入口”的说明已过时。

本次禁止模型和密钥读取，对学弟原9PDF执行正式入口的本地准备：9份、651页全部进入清单，原文件哈希一致；没有依赖旧解析器。**这只证明入口覆盖，不证明这些页已识读或原BUG已修好。**

本次索引10月16—18日保留的34份有候选输出的运行记录：原9个语义反例中，仅G344第13页有较早视觉版本的目标页结果；未查到当前版本对原9例的完整重测。不同文件、邻页上下文、清单准备不能替代原反例验收。

真实内容测试仍有警示。10月18日另一份21页G209施工图的v10停止检查点，经AI助手原图逐条复核632条候选，其中176条自动通过记录有168条原文一致、8条错误，原文一致比例95.45%；另有6条计价单位基准缺项。工程29个事前检查点仅8个正确采用，预算13点仅2个正确采用；由于运行被停止、查漏未完成，这些是检查点覆盖，不是完整流程最终召回率。

本次重新查看了G344第13页、新G209第9页和第20页代码列图像，并核对对应旧输出：现状高度与设计值的角色区别、5%误读为3%、边沟误作边坡、材料代号错读均有原图依据。**这些是较早版本的问题证据；后续v11已增加独立复读、编号/计价基准校验、跨页关联与窗口调度，但尚无修复后真实同口径成绩，不能把旧错误率冒充当前错误率，也不能仅凭代码修复就宣布消失。**

本次76项相关离线回归通过；10月18日整理曾通过409项后端及41项浏览器检查。它们验证运行、契约与失败边界，不是模型识别二率。本次无外部API调用、未读取密钥，原PDF、生产成果和识别代码哈希未变。

下一步应以原9个语义反例、G351原3对象、分类20页作为必查回归；保留真实观测等正例，防止靠删输出消灭误报。再用未参与调参的整文件，同时统计完整正确事实、误报、漏报、待审和未处理。必须验证对象、范围、角色、单位、工况及出处，待审/未处理不能从召回分母移走。当前适合带出处的辅助抽取，尚不能按无人审核的工程知识来源验收。
