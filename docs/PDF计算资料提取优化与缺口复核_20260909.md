# PDF计算资料提取优化与缺口复核

## 本轮结论

现有资料并非普遍缺少计算参数。部分计算表已在PDF解析阶段得到完整单元格，但后续没有转为可查询的业务记录。本轮优先补齐这一环节，不新增人工种子，不新增大模型API调用，也不重新执行整库OCR。

## 已完成的调整

- 根据表头识别“材料—参数—天然/饱和状态”等横向、纵向及合并表头结构，提取重度、黏聚力和内摩擦角；单位不明、数值含不等号或列数错位时不猜测取值。
- 区分计算所得稳定系数、要求安全系数和防治安全等级，保留工况、断面、危岩编号或破坏模式，避免把不同对象的相同数值合并。
- 按路线、章节标题及页面双栏顺序关联边坡，保留表格、单元格位置、PDF页码和章节来源。未明确对应边坡的表格留在提取结果中，不强行挂到邻近边坡。
- 将表题桩号不一致、正文与表格结论疑点列入待核验信息。仅从表格新增、尚未确认适用范围的工况结果暂不参与风险筛查；已有语义结果若命中同页相关疑点也受限制。
- 修正测量控制点的语义：原有13组控制点继续保存，但不再直接作为边坡起止点坐标。完整度下降不等于资料丢失。
- 边坡档案增加材料参数表；数据与接口页增加计算资料及待核验清单；风险页面和离线风险HTML增加结果使用限制。

这些样本用于检查程序回归，不能将其局部匹配率解释为全库准确率，更不能据此证明风险预测准确。尚未对全部扫描图纸、所有公式或全部字段建立完整金标准。风险研判继续保持历史资料筛查边界，不输出正式风险概率或实时安全保证。

最终72项自动测试全部通过，前端脚本语法检查通过。浏览器已检查数据与接口页的实际布局与待核验内容；其余页面的完整交互复测因浏览器工具配额限制未完成，不能把自动测试通过等同于全部人工验收完成。

## 现有资料中的具体待核验项

1. **G351第44页**：表4-5桩号与所在章节桩号不一致；天然工况表格写“基本稳定”，附近正文写“欠稳定”。保留原文，不自动选一个作为标准答案。
2. **G347（1361路段）第14页**：表4-4属于报告中的材料计算参数推荐表，不能默认每一处边坡都采用相同参数；现保留为未绑定候选。
3. 部分表格只给出计算结果或部分输入，尚不足以完整复现极限平衡计算。精确几何、滑面、条块与地下水条件需要逐算例核对。

## 下一步真正需要补充的内容

- **先确认已有资料中的歧义和使用口径**：上述桩号及评价结论冲突、选用的风险分级规则、不同破坏类型及工况的适用条件。不是重新索要整套规范。
- **若评估当前状态**：同一批边坡带日期的巡查、病害、治理落实及监测记录；如有位移、降雨和地下水序列，提供原始表格、单位和测点对应关系。设计文件中要求提供监测图表，不表示已经有实测序列。
- **若复现物理计算**：先选少量已有算例，补其原计算工程文件或可编辑断面、滑面、条块等缺失输入，不重复索要PDF已经包含的重度、黏聚力、内摩擦角。
- **若推进多模态接入**：已有测绘项目对应的原始影像、地形数据或三维模型及坐标信息。PDF中的成果图片不能替代数字原文件。

## 复跑方式

```powershell
# 原始PDF未变化时：重建基础/当前深度结果，重新校验缓存语义，更新两类离线HTML；不调用API
python scripts/rebuild_from_sidecars.py

# 独立原页回归评测，金标准不参与生产提取
python scripts/evaluate_engineering_extraction.py

# 全部自动测试
python -m unittest discover -s tests -q
```

原始PDF新增或修改时，应走正常PDF解析流水线；离线重建命令会检查原始文件清单及变更状态，拒绝使用旧逐页结果覆盖新资料。
