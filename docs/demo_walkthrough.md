# SlopeKG Demo 演示说明

## 1. 当前定位

当前 Demo 以 G209 K2388+976～K2435+900 工程资料包为样例，将原13条灾害点资料迁移为13个候选边坡，并围绕边坡组织灾害体、灾害类型候选评价、岩性地层、结构面、防护设计、稳定性分析、图纸和证据。

当前数据仍是“真实 PDF 抽样解析 + 规则整理 + 人工领域种子”的历史基线，不能作为当前现场风险结论。13个候选边坡的实体边界、属性和关系均保留待审核状态。

## 2. 页面划分

Demo 不再把所有能力集中在一页，当前提供：

1. `index.html`：项目总览和能力边界。
2. `slopes.html`：边坡档案、基础属性、关联数据和缺失项。
3. `graph.html`：边坡中心关系图谱、查询、局部子图和证据。
4. `data-status.html`：数据完整性、待接入数据源和预留接口。
5. `risk.html`：风险研判就绪度检查。

## 3. 推荐演示顺序

1. 打开“总览”，说明当前是历史资料基线，不是实时风险系统。
2. 进入“边坡档案”，查看13个候选边坡和风险数据完整度。
3. 选择一个边坡，展示坡高、坡度等缺失字段以及待接入的巡检、养护、监测和环境数据。
4. 进入“关系图谱”，展示边坡与灾害体、岩性、结构面、防护设计、稳定性和图纸的关系。
5. 点击防护工程，说明“有设计记录”不代表已建成或当前有效。
6. 进入“数据与接口”，展示监测、气象、养护、巡检、暴露对象和风险规则接口的接入状态。
7. 进入“风险研判”，选择边坡并检查阻断项。正式风险评估按钮保持禁用，避免数据和规则不完整时输出无依据结论。

## 4. 当前数据规模

- 3份 PDF；
- 245页；
- 13个候选边坡；
- 198个图谱节点；
- 365条关系；
- 7条证据记录；
- 13份数据完整性报告；
- 当前所有边坡均未达到正式风险研判条件。

## 5. 演示表述

可以按以下口径介绍：

> 当前 Demo 先将一个真实 G209 工程资料包组织为以边坡为核心的历史基线图谱。系统区分边坡、灾害体、防护设计、稳定性分析和来源证据，并逐项显示已有、缺失、待审核和待接入数据。前端拆分为边坡档案、关系图谱、数据接口和风险研判等页面。风险页面目前只做就绪度检查，待动态数据、正式规则和人工审核流程接入后再开放正式评估。
