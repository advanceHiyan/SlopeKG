# 自动抽取的候选追踪与回归验收

## 自动化方法

1. 两层表头按父指标、工况、单位定位稳定系数列，支持列换序和合并表头。下滑力、安全系数阈值不作为实测稳定系数。丢失列边界的扁平表格仍只接受已能确定列含义的保守重建格式，其他格式留作未解析候选。
2. 产状先识别数值对，再识别同句中的岩层、节理或坡面对象。保留小数；数值范围不压成端点；新章节的桩号阻断错误继承。既有的表格和命名产状解析仍保留。
3. 材料分类优先采用“坡体由……组成”“边坡地层岩性为……”等明确主体证据。覆盖层、裂隙填充物、滑床分别记录。明确主体证据不足时，原词项归一化后备方法仍存在，不能宣称已全面解决材料分类。
4. 语义补全检查逐组比较来源产状与已抽取产状，字段非空不再代表完整。沿用原来的有限补全流程；离线缓存重验不会请求模型补齐。

上述方法不读取评测答案，也不按文件名、路线名或具体桩号分支。抽取模块只读取原始资料的解析结果；评分脚本在抽取结束后独立读取答案。

## 处理记录

自动图谱包含 `processing_audit`，正常建图还写出
`output/demo/extracted/processing_audit.<mode>.json`。候选包含原句、页码、文档、对象角色和处理状态：

| 状态 | 含义 |
|---|---|
| represented | 同对象、同数值的产状已出现在图谱 |
| not_extracted | 来源存在有明确对象的产状，但输出没有对应项 |
| lost_after_extraction | 确定性抽取已有对应项，建图后丢失 |
| needs_object_review | 对象不明、数值为范围或超限，不能直接写成确定事实 |
| needs_station_review | 最近章节桩号与当前关联坡段不一致 |
| scoped_material_evidence | 保留材料提及及其对象角色，尚不等于正确分类结论 |
| table_not_extracted / table_parse_failed | 检测到稳定系数表头，但没有成功提取结果 |
| table_association_unresolved | 表内结果已识别，但无法唯一关联坡段 |

这些是排查线索，**不能把候选数量当成召回率分母**。当前只覆盖保留的章节文本样本和表格解析文件，不覆盖所有事实种类，也无法发现PDF/OCR尚未识别的信息。候选中可能存在重复描述、目录、图注、原文冲突或识别噪声。

## 验收与防止答案泄漏

- 在修改前保存原始PDF哈希、答案哈希、基线图谱和首次评分。参与问题诊断的样本归入开发回归集，即使曾经命名为holdout。
- 对新旧图谱使用同一份固定答案和同一评分程序，检查原先正确事实是否丢失，同时审查全库科学字段增删。
- 测试改变数值、列顺序、对象和版式，加入范围、跨对象、小数及跨章节的反例。测试通过只能证明这些约束有效，不能替代新文档评测。
- 独立测试按整份原始文档划分。改文件名或挑同文档其他坡段不构成未见文档。
- `PYTHONPATH=src python scripts/validate_evaluation_partition.py manifest.json` 校验划分声明；发现重复内容、已暴露来源或没有独立文档时以退出码2拒绝独立验收声明。

清单字段示例：

```json
{
  "exposed_source_sha256": ["先前用于开发的原始PDF的64位SHA256"],
  "documents": [
    {"id": "报告标识", "source_sha256": "原始PDF的64位SHA256", "split": "development"}
  ]
}
```

要取得独立验收结果，还需要至少一个未参与开发的完整报告，标为 `holdout`，先固定标注口径再运行。校验器只能检查已声明的暴露记录，不自动证明统计代表性。
