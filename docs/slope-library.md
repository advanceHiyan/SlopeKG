# 自动化识别到边坡资料库

识别任务完成或部分完成后，先保存资料，再按实际边坡归集。新任务不再要求生成评估文件或执行评估交接。

- 入口：导航「边坡资料库」，或智能识别任务中的「边坡资料库」。其他路线的识别详情也有入库入口。
- 自动保存：五条路线经 `DemoPipeline.run` 完成后，统一接收原件、对象、原文候选、页码和图片位置。只准备资料时不会入库。
- 补存旧任务：从任务打开资料库，选择「保存 / 重试入库」。重复保存同一结果不会重复建档；识别结果发生变化时保留版本。
- 原件保护：核对识别时的 SHA-256 后保存原 PDF 副本。原目录后续修改或删除不会覆盖已归档原件。指纹不符的来源暂不入库，其他来源照常保存。
- 归属核对：同一原件的重跑复用来源绑定。不同 PDF 不凭同名合并；核对人选择实际边坡，填写依据后关联。显式的同文档父子关系保留在同一边坡下，局部属性仍保留局部对象。
- 候选边界：入库不等于字段确认。来源错误、跨文件引用、无原页证据等条目保留并标为暂不采用，不覆盖既有人工字段。
- 图片边界：照片、剖面图、示意图、工程图和计算草图只归档。扫描调查表仍识别文字、勾选项、数值及行列关系。无法明确归属的图片作为文档附件保存。

数据位置为 `output/demo/slope-library/`：`library.sqlite3` 保存边坡、来源关联、识别版本和处理记录；`sources/` 保存按指纹命名的原件。备份时整体保留该目录。文件不提交到 Git。旧字段档案、旧评估记录与相关代码保留。新 Agent 任务只保留调用回执，不重复保存含图片的整份模型请求；原页和识别产物继续保留。

本轮没有改变工程判定规则，没有新增检查表、评估表或时序数据功能，也没有修改项目管理台账。后续风险识别应选取边坡下已核对的资料；规则与甲方核对完成后再接入。

验证包括隔离数据库生命周期测试、扫描表与图纸处理边界测试、相关离线回归、正常页面入口的浏览器实点，以及固定开放开发页的模型改前/改后记录。模型自查和单页回归均不能代表整库准确率。
