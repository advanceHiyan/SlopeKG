# 多源多模态信息抽取技术调研

## 1. 调研背景

公路边坡知识图谱的底层构建需要从多类资料中自动或半自动提取知识，包括结构化表格、普通文本、扫描文档、工程图纸、现场照片、遥感影像、三维点云等。不同数据形态的信息承载方式差异很大，单一 OCR、单一大模型或单一规则系统都难以稳定覆盖全部场景。

因此，推荐采用“多通道抽取 + 统一 Schema + 证据溯源 + 人工校核”的工程路线：

```text
原始数据
  -> 文件识别与切分
  -> 文本抽取通道
  -> 表格抽取通道
  -> OCR/扫描件抽取通道
  -> 图纸/图片理解通道
  -> 遥感/点云解析通道
  -> 统一知识 Schema
  -> 实体对齐与消歧
  -> 图数据库/向量库/文件存储
```

## 2. 信息抽取总体分层

### 2.1 物理层解析

物理层关注“数据从哪里来、页面或图像上有什么区域”：

- 文件级：PDF、Word、Excel、图片、CAD、遥感影像、点云文件。
- 页面级：页码、版面、标题、段落、表格、图片、图纸、页眉页脚。
- 区域级：文本块、表格区域、图注、标题栏、坐标标注、图例、符号。
- 空间级：bbox、页内坐标、地理坐标、桩号、三维坐标、时间戳。

### 2.2 语义层抽取

语义层关注“这些内容代表什么知识”：

- 实体：路线、合同段、桩号区间、边坡、危岩体、不稳定边坡、地层、岩性、结构面、防护措施、规范、图纸等。
- 属性：坡高、坡长、坡度、倾向、倾角、风化程度、稳定系数、锚杆长度、喷砼厚度、安全等级等。
- 关系：位于、属于、发育、采用、依据、影响、导致、防护、对应图纸、来源文件等。
- 事件：崩塌、滑移、落石、降雨诱发、人工开挖、治理施工、监测预警等。
- 规则：评价标准、设计工况、安全系数阈值、防治工程安全等级划分等。

### 2.3 图谱层融合

图谱层关注“抽出来的知识如何可靠地合并”：

- 实体归一：如“该段危岩体”“本段边坡”“K2410+330-K2410+445 左侧危岩体”对齐为同一实体。
- 单位归一：m、mm、kPa、度、KN/m3 等统一存储。
- 空间归一：桩号、左右侧、坐标、图纸断面位置之间建立映射。
- 来源溯源：每个实体、属性、关系都保留文件名、页码、bbox、抽取方式和置信度。
- 冲突处理：同一属性多来源不一致时保留多版本和来源，进入人工校核流程。

## 3. 表格信息抽取

### 3.1 表格类型

表格信息应先按来源分类：

- Excel/CSV 表格：优先使用结构化解析，不应 OCR。
- 文字型 PDF 表格：利用 PDF 文字坐标、线框、单元格位置解析。
- 扫描表格/图片表格：需要 OCR、表格检测和表格结构识别。
- 工程图纸标题栏/工程数量表：通常是 PDF 图形、文字和表格混合，需要版面分析和局部 OCR。

### 3.2 技术流程

```text
表格区域检测
  -> 表格结构识别
  -> 单元格内容抽取/OCR
  -> 表头层级恢复
  -> 单元格语义解释
  -> 结构化 JSON/CSV
  -> 图谱实体与属性映射
```

### 3.3 常用技术

- `pandas/openpyxl`：适合 Excel、CSV 等结构化表格。
- `pdfplumber`：适合文字型 PDF 的表格和文本坐标抽取。
- `Camelot/Tabula`：适合带线框或规则版式的文字型 PDF 表格。
- `PaddleOCR PP-Structure`：适合中文扫描表格、文档版面和图片表格。
- `Table Transformer`：基于深度学习的表格检测与结构识别。
- `PdfTable`：集成表格检测、OCR、结构识别和版面模型的工具路线。

### 3.4 在公路边坡场景中的抽取对象

- 勘察目录：灾害点编号、桩号区间、左右侧、灾害类型、图号、页码。
- 稳定性计算表：岩性、风化程度、工况、重度、黏聚力、内摩擦角、稳定系数、破坏形式。
- 设计标准表：安全等级、工况、安全系数阈值。
- 工程数量表：锚杆、喷砼、钢筋网、截水沟、急流槽、挡墙等工程量。
- 图纸目录：图纸类型、图号、页码、对应灾害点。

### 3.5 推荐输出格式

```json
{
  "table_id": "施工图设计文件_p32_稳定性计算表",
  "source": {
    "file": "G209-2388.976-2435.900-施工图设计文件-185203.pdf",
    "page": 32
  },
  "rows": [
    {
      "对象": "K2410+330-K2410+445 左侧危岩体",
      "岩性": "砂质页岩、页岩",
      "风化程度": "强风化",
      "工况": "天然",
      "Fs": 1.22,
      "破坏形式": "滑移式"
    }
  ]
}
```

## 4. 普通文本信息抽取

### 4.1 适用对象

- 文字型 PDF 正文。
- Word/Markdown 报告。
- 设计说明、勘察报告、规范条文。
- OCR 后的扫描文本。

### 4.2 抽取任务

- 命名实体识别：识别边坡工程领域实体。
- 属性抽取：从实体上下文中抽取数值、单位和描述。
- 关系抽取：识别实体之间的语义关系。
- 事件抽取：识别灾害发生、诱发、治理、监测等事件。
- 规则抽取：从规范和设计说明中抽取判定标准、工况和阈值。
- 实体链接：将不同表述映射到统一实体。

### 4.3 技术路线

建议采用“规则 + NLP/LLM + 本体约束”的组合：

```text
文本切分
  -> 规则抽取强格式字段
  -> LLM/NER 抽取实体和属性
  -> 关系抽取
  -> 本体和单位校验
  -> 证据绑定
  -> 人工抽检
```

规则适合抽取稳定格式，例如：

```text
K2410+330-K2410+445
302º∠70º
Fs = 1.22
C20 喷砼
Ф8@300×300mm
锚杆间距 2.1×2.1m
```

LLM 适合抽取语义性较强的内容，例如：

- 灾害成因机制。
- 稳定性分析结论。
- 防治设计理由。
- 规范条文解释。
- 多句话中的隐含关系。

### 4.4 图谱映射示例

```json
{
  "entity": "K2410+330-K2410+445左侧危岩体",
  "type": "危岩体",
  "attributes": {
    "位置": "G209 K2410+330-K2410+445 左侧",
    "地貌": "中低山地貌区",
    "岩性": "砂质页岩、页岩",
    "防护措施": "坡面清危+挂网锚喷"
  },
  "relations": [
    ["属于", "G209宣恩县部分路线段"],
    ["发育岩性", "砂质页岩、页岩"],
    ["采用防护措施", "挂网锚喷"]
  ],
  "evidence": {
    "file": "施工图设计文件",
    "page": 32,
    "confidence": 0.86
  }
}
```

## 5. 文本图片与扫描件抽取

### 5.1 适用对象

- 扫描 PDF。
- 拍照文档。
- 规范扫描件。
- 图纸中的文字标注。
- 图片表格。

### 5.2 技术流程

```text
图像渲染/读取
  -> 去噪、纠偏、增强、切边
  -> 版面分析
  -> OCR
  -> 阅读顺序恢复
  -> 表格/标题/图注识别
  -> 文本语义抽取
  -> 结果校验
```

### 5.3 常用技术

- `Tesseract`：传统开源 OCR，适合简单页面；复杂中文工程文档效果有限。
- `PaddleOCR`：中文 OCR、表格识别和文档结构解析较完整。
- `LayoutLMv3`：融合文本、图像和版面信息，适合表单、票据、复杂文档理解。
- `Donut`：OCR-free 文档理解模型，直接从文档图像生成结构化结果。
- 多模态大模型：适合复杂页面问答、图文理解和辅助标注，但批处理时需要结构化约束和置信度校验。

### 5.4 对本项目的启示

`2021地质灾害评估规范.pdf` 属于扫描型规范，普通 PDF 文本抽取基本无效。推荐先做 OCR，并保留：

- 页码。
- 文本块 bbox。
- OCR 置信度。
- 标题层级。
- 表格区域。
- 图注和条文编号。

随后再进行术语、条文、评价流程、评价指标、判定规则的结构化抽取。

## 6. 非文本图片信息抽取

### 6.1 现场照片

现场照片可抽取的信息包括：

- 场景类型：边坡、道路、挡墙、裸岩、植被、水沟等。
- 灾害迹象：崩塌、落石、裂缝、冲刷、剥落、危岩块体。
- 工程构筑物：锚杆、喷砼、防护网、挡墙、截水沟、急流槽。
- 状态描述：岩体破碎、坡面裸露、植被覆盖、局部失稳等。

常用技术：

- 目标检测：YOLO、DETR 等。
- 语义分割/实例分割：Mask R-CNN、SegFormer、SAM/SAM2 等。
- 视觉语言模型：生成图片描述、区域问答、弱标注。
- 变化检测：对比治理前后、灾害前后或多期巡检照片。

### 6.2 工程图纸、地质图和断面图

工程图纸不能仅作为普通图片处理，应做图纸理解。可抽取的信息包括：

- 标题栏：项目名、图号、图名、比例、设计单位、页码。
- 图纸类型：平面图、断面图、立面图、大样图、工程地质图。
- 标注文本：桩号、高程、坡度、尺寸、锚杆长度、材料规格。
- 图例和符号：岩性、结构面、危岩边界、防护工程、道路边线。
- 几何对象：坡面线、地面线、断面线、等高线、边界线。

推荐处理顺序：

```text
图纸页识别
  -> 标题栏 OCR
  -> 图名/图号/比例抽取
  -> 文字标注 OCR
  -> 关键符号和线条检测
  -> 图纸对象结构化
  -> 与灾害点实体对齐
```

如果存在 CAD/DWG 原文件，应优先解析 CAD 图元，而不是从 PDF 渲染图像中反推几何。

### 6.3 分阶段建议

第一阶段：

- 抽图纸标题栏。
- 抽图名、图号、比例、桩号、页码。
- 抽主要文字标注。
- 建立图纸与灾害点的对应关系。

第二阶段：

- 识别锚杆、截水沟、防护网、挡墙等符号。
- 抽取坡面线、断面线和几何尺寸。
- 建立二维图纸对象与工程实体的空间关系。

## 7. 三维遥感影像、点云与 DEM 信息抽取

### 7.1 数据类型

公路边坡场景中的三维和遥感数据可能包括：

- UAV 正射影像。
- 倾斜摄影三维模型。
- LiDAR 点云。
- DEM/DSM。
- InSAR 形变数据。
- 光学/SAR 多时相遥感影像。
- 三维 mesh 或实景模型。

### 7.2 可抽取信息

- 地形属性：高程、坡度、坡向、曲率、起伏度。
- 边坡几何：坡高、坡长、坡脚、坡顶、坡面角。
- 灾害地貌：滑坡体、崩塌堆积体、裂缝、陡坎、冲沟、落石堆积。
- 岩体结构：节理面、层面、结构面倾向倾角。
- 地表覆盖：裸岩、植被、道路、水体、构筑物。
- 时序变化：位移、沉降、形变速率、滑塌边界变化。

### 7.3 技术流程

```text
数据配准
  -> 去噪和滤波
  -> 地面/非地面分类
  -> DEM/DSM 生成
  -> 地形因子计算
  -> 影像/点云分割
  -> 变化检测
  -> 空间对象抽取
  -> 图谱入库
```

### 7.4 常用技术

- `GDAL/Rasterio`：栅格遥感影像处理。
- `PDAL`：点云数据处理。
- `Open3D`：点云几何计算、法向量、平面拟合。
- `CloudCompare`：点云查看、配准、分割、距离计算。
- `QGIS/PostGIS`：空间数据管理和可视化。
- `PointNet++/KPConv/Point Transformer`：点云分类和语义分割。
- 遥感基础模型：遥感影像分类、目标检测、变化检测。
- InSAR 算法：地表形变监测。

### 7.5 对边坡图谱的价值

三维和遥感数据可以补充传统文档难以提供的动态空间信息：

- 从 DEM 计算坡度、坡向、汇水条件。
- 从点云估算坡面几何和结构面产状。
- 从多期影像识别新增裂缝、滑塌边界和治理变化。
- 从 InSAR 获取形变速率和异常区域。
- 将空间对象与文档中的灾害点、桩号、治理措施进行融合。

## 8. 面向公路边坡知识图谱的统一 Schema

### 8.1 核心实体建议

- `Project`：项目。
- `RouteSegment`：路线段。
- `StakeRange`：桩号区间。
- `HazardPoint`：灾害点。
- `Slope`：边坡。
- `RockMass`：岩体/危岩体。
- `UnstableSlope`：不稳定边坡。
- `Stratum`：地层。
- `Lithology`：岩性。
- `StructuralPlane`：结构面。
- `FailureMode`：破坏模式。
- `StabilityAnalysis`：稳定性分析。
- `ProtectionMeasure`：防护措施。
- `EngineeringQuantity`：工程数量。
- `Drawing`：图纸。
- `Document`：文档。
- `StandardClause`：规范条文。
- `RemoteSensingObject`：遥感/三维空间对象。

### 8.2 核心关系建议

- `BELONGS_TO`：属于。
- `LOCATED_AT`：位于。
- `HAS_STAKE_RANGE`：具有桩号范围。
- `HAS_LITHOLOGY`：具有岩性。
- `HAS_STRATUM`：具有地层。
- `DEVELOPS_STRUCTURAL_PLANE`：发育结构面。
- `HAS_FAILURE_MODE`：具有破坏模式。
- `AFFECTED_BY`：受某因素影响。
- `USES_MEASURE`：采用防护措施。
- `BASED_ON`：依据规范或资料。
- `RECORDED_IN`：记录于文档。
- `SHOWN_IN`：显示于图纸。
- `HAS_EVIDENCE`：具有证据。
- `SPATIALLY_OVERLAPS`：空间重叠。
- `TEMPORALLY_CHANGES_TO`：时序变化。

### 8.3 证据字段

每条知识都应保留证据：

```json
{
  "source_file": "G209-2388.976-2435.900-施工图设计文件-185203.pdf",
  "page": 96,
  "bbox": [100, 120, 500, 180],
  "extractor": "ocr+llm",
  "confidence": 0.86,
  "review_status": "pending"
}
```

## 9. 推荐落地路线

### 9.1 第一阶段：文档与表格可用抽取

目标是快速构建可验证的最小图谱。

- 完成 PDF 文件识别、页码切分和文本抽取。
- 对扫描规范做 OCR。
- 抽取目录表、稳定性计算表、工程数量表。
- 建立 13 个灾害点的初始实体。
- 按桩号对齐勘察报告和施工图设计文件。
- 所有结果绑定文件名、页码和证据。

### 9.2 第二阶段：领域语义抽取

目标是抽取工程地质和防护设计知识。

- 抽取地形地貌、地层岩性、地质构造。
- 抽取结构面产状、坡面产状、岩层产状。
- 抽取灾害成因机制和稳定性结论。
- 抽取防护措施、材料规格、施工要求。
- 建立规范条文与设计依据之间的关系。

### 9.3 第三阶段：图纸和图片理解

目标是让图纸和图片进入图谱。

- 抽取图纸标题栏、图号、图名、比例。
- 抽取图纸中的桩号、高程、尺寸和主要标注。
- 识别图纸类型：平面图、断面图、立面图、大样图。
- 建立图纸页与灾害点、防护措施的关系。
- 对现场照片做目标检测和视觉描述。

### 9.4 第四阶段：遥感与三维数据融合

目标是接入动态空间信息。

- 支持 DEM、正射影像、点云和 InSAR 数据接入。
- 抽取坡度、坡向、坡高、坡脚、坡顶等地形属性。
- 识别滑坡体、裂缝、崩塌边界、裸岩、道路等空间对象。
- 支持多期变化检测。
- 将空间对象与桩号、灾害点、图纸和文档证据融合。

## 10. 风险与注意事项

- OCR 错误会向后传播，必须保留置信度并设置人工校核。
- 工程图纸几何抽取难度高，应先做标题栏和文字标注，不宜一开始承诺完整图元理解。
- 规范条文抽取需要保持原文证据，避免 LLM 过度改写。
- 表格合并单元格和多级表头容易错位，需要结构化校验。
- 桩号、左右侧、页码、图号是多源对齐的关键字段，必须优先保证准确。
- 遥感/点云数据需要统一坐标系，否则无法和图谱实体可靠融合。
- 图谱中的每条知识都应带来源，GraphRAG 问答必须能回链到文件和页码。
